.. py:function:: source_unique_records(records: list[dict[str, object]]) -> list[dict[str, object]]

   Keep mirrors for audit, but grade/select only one exact source per target.

   Failures are deliberately excluded: merged review must not retry a failed
   decision or clear its pending flags in the same run. Rejected/held documents
   are handled by the existing reviewer and eligibility gate.


.. py:function:: target_has_sufficient_evidence(records: collections.abc.Iterable[collections.abc.Mapping], *, keep_top: int, coverage: collections.abc.Mapping[str, str] | None = None) -> bool

   Check if a target has met its sufficiency requirements.

   A target is considered sufficient when:
   - It has collected at least `keep_top` accepted documents, AND
   - If coverage is specified, all required labels have been covered.
