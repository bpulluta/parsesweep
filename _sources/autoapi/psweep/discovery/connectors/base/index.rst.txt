.. py:class:: BaseSeekerConnector

   Bases: :py:obj:`abc.ABC`


   Abstract interface for search discovery (seeker stage).

   Implementations discover candidate URLs from a query.
   Results are normalized to DiscoveryCandidate model.


   .. py:method:: discover(seeker_input: SeekerInput) -> list[dict[str, Any]]
      :abstractmethod:


      Discover candidate URLs from a query.

      :returns:

                Normalized candidate records, each shaped like::

                    {
                        "url": str,
                        "source": str,
                        "title": str | None,
                        "snippet": str | None,
                        "reasons": list[str],
                    }
      :rtype: list[dict[str, Any]]

      :raises RuntimeError: If the provider is unavailable or the API key is missing.
      :raises ValueError: If the query is invalid.



   .. py:method:: supports_provider(provider: str) -> bool
      :abstractmethod:


      Check if this connector supports the given provider name.
