psweep.discovery.candidate_selector
===================================

.. py:module:: psweep.discovery.candidate_selector

.. autoapi-nested-parse::

   Per-target candidate selection with configurable exclusion policies.

   Source URL/title/snippet evidence is filtered only by supplied draft,
   identity and relevance rules. No domain-specific exclusion vocabulary is
   imposed by default. Within each target's pool, supported files and more
   recent filename dates are preferred; undated candidates remain eligible.
   Per-target limits keep larger candidate pools from crowding out others.

   Selects the best candidate(s) per target from seeker output.

   :param exclude_draft: When ``True`` (default), apply the supplied draft patterns to
                         source URL/title/snippet evidence before recency ranking.
   :param draft_patterns: Domain-provided case-insensitive ``re.search`` patterns.
                          Omitted or empty lists impose no draft exclusions.


   .. py:method:: select(candidates_by_target: list[list[psweep.discovery.models.DiscoveryCandidate]], primary_per_target: int = 1, target_contexts: list[dict[str, object]] | None = None, include_metrics: bool = False) -> tuple[list[psweep.discovery.models.DiscoveryCandidate], list[str]] | tuple[list[psweep.discovery.models.DiscoveryCandidate], list[str], list[dict[str, Any]]]

      Select up to *primary_per_target* candidates per target.

      Steps per target:
      1. Draft filter (if ``exclude_draft=True``).
      2. Sort by parsed effective date descending (most recent first).
      3. Take the top *primary_per_target* candidates.

      :param candidates_by_target: Parallel list where index *i* holds the candidates returned by
                                   the seeker for target *i*.
      :param primary_per_target: Maximum number of candidates to select for each target.
                                 Defaults to ``1``.
      :param target_contexts: Optional per-target metadata (parallel to *candidates_by_target*)
                              used to enrich selection notes and metrics.
      :param include_metrics: When ``True``, also return the per-target selection metrics.

      :returns: ``(selected, notes)``, or ``(selected, notes, target_metrics)``
                when ``include_metrics=True``, where:

                - ``selected`` is the flat list of selected candidates, one group
                  per target in input order;
                - ``notes`` holds human-readable selection log entries for the
                  manifest;
                - ``target_metrics`` holds per-target selection metrics (present
                  only when ``include_metrics=True``).
      :rtype: tuple
