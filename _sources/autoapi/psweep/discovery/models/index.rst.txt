.. py:class:: CandidateScore

   Score signals and acceptance classification for a candidate URL.


   .. py:method:: acceptance_class() -> str

      Classify the weighted score into an acceptance tier.

      :returns: ``"accepted"`` (≥ 0.75), ``"needs_review"`` (≥ 0.45), or
                ``"rejected"`` (< 0.45).
      :rtype: str



   .. py:method:: to_dict() -> dict[str, Any]

      Serialize the score signals and derived fields to a plain dict.

      :returns: Keys: ``url_signal``, ``anchor_signal``, ``content_signal``,
                ``trust_signal``, ``weights``, ``total``, ``acceptance_class``.
      :rtype: dict[str, Any]



   .. py:method:: weighted_total() -> float

      Compute the weighted sum of all signal scores, clamped to [0, 1].

      :returns: Weighted score in the range ``[0.0, 1.0]``.
      :rtype: float



.. py:class:: DiscoveryCandidate

   Normalized candidate URL and validation/scoring details.


   .. py:method:: to_dict() -> dict[str, Any]

      Serialize this candidate to a plain dict for JSON output.

      :returns: Flat representation suitable for writing to the discovery manifest.
                ``status`` falls back to ``score.acceptance_class()`` when not
                explicitly set.
      :rtype: dict[str, Any]



.. py:class:: DiscoveryManifest

   Run-level manifest model for discovery outputs and provenance.


   .. py:method:: to_dict() -> dict[str, Any]

      Serialize the full manifest to a JSON-compatible dict.

      :returns: Complete manifest representation, including all candidates
                serialized via ``DiscoveryCandidate.to_dict()``.
      :rtype: dict[str, Any]
