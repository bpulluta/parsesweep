.. py:class:: DiscoveryPolicyEvaluator

   Evaluate robots.txt and manual ToS acknowledgement policy controls.


   .. py:method:: evaluate(*, url: str, ssl_verify: bool, request_headers: dict[str, str] | None = None, robots_policy_mode: str = DEFAULT_ROBOTS_POLICY_MODE, tos_policy_mode: str = DEFAULT_TOS_POLICY_MODE, acknowledged_tos_domains: list[str] | None = None) -> PolicyCheckResult

      Evaluate robots.txt and ToS-acknowledgement policy for a URL.

      :param url: The target URL to check.
      :param ssl_verify: Whether TLS verification is used when fetching ``robots.txt``.
      :param request_headers: Optional headers for the ``robots.txt`` request (a default
                              User-Agent is used when omitted).
      :param robots_policy_mode: ``ignore``, ``warn``, or ``enforce`` (unknown values normalize to
                                 ``ignore``). Non-``ignore`` modes fetch and consult ``robots.txt``.
      :param tos_policy_mode: ``ignore``, ``warn``, or ``enforce`` for terms acknowledgement.
      :param acknowledged_tos_domains: Hosts/parent domains the caller has acknowledged terms for.

      :returns: ``allowed`` is ``False`` only under ``enforce`` when a control is
                violated; ``warn`` records ``warning_codes`` but stays allowed.
      :rtype: PolicyCheckResult



   .. py:attribute:: DEFAULT_USER_AGENT
      :value: 'ParseSweep/2.0 (+discovery)'
