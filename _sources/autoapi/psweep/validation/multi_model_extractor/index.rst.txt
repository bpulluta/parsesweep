psweep.validation.multi_model_extractor
=======================================

.. py:module:: psweep.validation.multi_model_extractor

.. autoapi-nested-parse::

   Multi-Model Extractor for QA/QC Validation.

   Runs document extraction with multiple AI models and saves outputs
   to organized subfolders for comparison.

   Model tiers and credentials are resolved exclusively through the unified
   :class:`~psweep.config.model_registry.ModelRegistry`. Callers pass the registry
   plus the ``validation.models`` tier references; this module resolves each tier to a
   concrete model and its LLM kwargs (provider/api_key/endpoint) via
   ``registry.to_llm_kwargs`` — never threading a provider directly.

   .. rubric:: Examples

   .. code-block:: python

       from psweep.validation.multi_model_extractor import run_multi_model_extraction

       output_files = run_multi_model_extraction(
           doc_text="Full document text...",
           doc_name="austin_energy_tariff",
           schema=loaded_schema,
           registry=registry,
           model_tiers=["primary", "secondary"],
           output_dir=Path("processed/validation"),
       )

   .. rubric:: Notes

   Output Structure::

       processed/validation/{doc_name}/
           {model_name}.json  (one file per model)
           metadata.json

   Run extraction with multiple models resolved through the model registry.

   :param doc_text: Full document text to extract from
   :type doc_text: str
   :param doc_name: Document name (without extension, used for output folder)
   :type doc_name: str
   :param schema: JSON schema for extraction
   :type schema: dict
   :param registry: Unified :class:`ModelRegistry` — the single source of model
                    tier resolution and credential (LLM kwargs) threading.
   :type registry: ModelRegistry
   :param model_tiers: Ordered list of tier/model references (e.g. the
                       ``validation.models`` list). Resolved and de-duplicated by concrete model.
   :type model_tiers: Sequence[str]
   :param output_dir: Base directory for QA/QC outputs (e.g., "processed/")
   :type output_dir: Path
   :param max_context_chars: Maximum characters to process
   :type max_context_chars: int
   :param timeout_seconds: Per-request LLM timeout for each model extraction.
   :type timeout_seconds: Optional[int]
   :param runtime_artifact: Optional compiled runtime artifact for lineage metadata
   :type runtime_artifact: Optional[Dict[str, Any]]
   :param run_id: Optional deterministic run identifier for this invocation
   :type run_id: Optional[str]

   :returns: Dict mapping concrete model name to ModelExtractionResult
   :rtype: Dict[str, ModelExtractionResult]
