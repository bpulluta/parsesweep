.. py:function:: evidence_paths(schema: dict[str, Any]) -> list[tuple[str, ...]]

   Return paths of ``{value, quote}`` evidence objects (``*`` = array item).

   An object whose properties are exactly ``value`` and ``quote`` is an
   evidence field; both must be required, ``value`` must accept null, and
   ``quote`` must be a nullable string.


.. py:function:: load_schema(schema_path: str | pathlib.Path) -> dict[str, Any]

   :type schema_path: Union[str, Path]

   :returns: Parsed JSON schema as dictionary
   :rtype: Dict[str, Any]

   :raises ConfigurationError: If the file is missing or not valid JSON
