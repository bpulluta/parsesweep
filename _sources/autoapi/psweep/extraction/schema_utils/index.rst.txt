.. py:function:: build_schema_validator(schema: dict[str, Any])

   Validate a schema definition and return its format-aware validator.


.. py:function:: evidence_paths(schema: dict[str, Any]) -> list[tuple[str, ...]]

   Return paths of ``{value, quote}`` evidence objects (``*`` = array item).

   An object whose properties are exactly ``value`` and ``quote`` is an
   evidence field; both must be required, ``value`` must accept null, and
   ``quote`` must be a nullable string.


.. py:function:: load_schema(schema_path: str | pathlib.Path) -> dict[str, Any]

   Load JSON schema from file.

   :param schema_path: Path to JSON schema file
   :type schema_path: Union[str, Path]

   :returns: Parsed JSON schema as dictionary
   :rtype: Dict[str, Any]

   :raises ConfigurationError: If the file is missing or not valid JSON


.. py:function:: record_validator()

   Load the canonical record-envelope validator once per process.


.. py:function:: schema_diagnostics(errors, *, limit: int = 8, width: int = 120) -> list[str]

   Bounded structural diagnostics for schema errors, never echoing values.

   Each line names the failing path and rule (plus missing/unexpected key names
   and the expected type); at most ``limit`` lines of ``width`` characters.


.. py:function:: strict_compatible(node: Any) -> bool

   True when every object is closed and fully required, without unsupported keywords.


.. py:function:: validate_payload(data: Any, validator: Any) -> None

   Raise a sanitized ``SchemaValidationError`` when ``data`` violates ``validator``.

   The diagnostic names the failing schema path and rule only, never the value.
