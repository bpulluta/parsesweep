.. py:class:: DocumentExtractor(api_key: str | None = None, model: str = DEFAULT_MODEL, max_context_chars: int = DEFAULT_MAX_CONTEXT, provider: str | None = None, azure_endpoint: str | None = None, azure_api_version: str | None = None, context_windows: dict[str, int] | None = None, base_url: str | None = None, timeout: int | None = None, reasoning_models: list[str] | None = None)

   Domain-agnostic, schema-driven document extractor (LLM calls via LiteLLM).

   .. rubric:: Examples

   >>> extractor = DocumentExtractor(api_key="sk-...")
   >>> result = extractor.extract(text, schema)
   >>> print(f"Extracted: {result.data}")
   >>> print(f"Confidence: {result.completeness_score:.0%}")

   Initialize document extractor.

   :param api_key: API key for the LLM provider
   :type api_key: str
   :param model: Model to use (default: gpt-4o-mini)
   :type model: str
   :param max_context_chars: Maximum characters to extract from document (default: 400000)
   :type max_context_chars: int
   :param provider: LLM provider ("openai", "azure", "anthropic", "gemini", etc.)
   :type provider: str
   :param azure_endpoint: Azure OpenAI endpoint URL (for Azure provider)
   :type azure_endpoint: str
   :param azure_api_version: Azure API version (for Azure provider)
   :type azure_api_version: str
   :param context_windows: Optional {model-name -> max prompt tokens} map for the
                           fail-fast context-budget guard (from ``model_context_windows`` in
                           config). No model names are hardcoded.
   :type context_windows: Optional[Dict[str, int]]
   :param base_url: Optional endpoint override for OpenAI-compatible proxies
                    (LiteLLM, OpenRouter, vLLM, etc.). When set, all calls are routed
                    through this URL regardless of model name.
   :type base_url: Optional[str]
   :param timeout: Per-request LLM timeout in seconds. If omitted, LLMClient
                   uses LLM_TIMEOUT env var or its default timeout.
   :type timeout: Optional[int]
   :param reasoning_models: Optional extra reasoning-model markers (from ``reasoning_models``
                            in config), unioned with the built-in defaults. No model names are
                            hardcoded in universal code beyond provider-neutral defaults.
   :type reasoning_models: Optional[List[str]]


   .. py:method:: extract(text: str, schema: dict[str, Any]) -> ExtractionResult

      Extract structured data from document.

      This method orchestrates:

      1. LLM Structured Extraction - Fast, schema-driven parsing
      2. Post-processing - Normalization

      :param text: Full document text to extract from
      :type text: str
      :param schema: JSON schema defining structure to extract (must have 'type' and 'properties')
      :type schema: Dict[str, Any]

      :returns: ExtractionResult containing:

                - data: Extracted structured data matching schema
                - completeness_score: 0-1 confidence score
                - cost: Total API cost in USD
                - processing_time: Total time in seconds
                - validation_notes: List of warnings/insights
      :rtype: ExtractionResult

      .. rubric:: Examples

      >>> result = extractor.extract(pdf_text, tariff_schema)
      >>> if result.completeness_score > 0.8:
      >>>     print("High confidence extraction!")
