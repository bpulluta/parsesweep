.. py:function:: extract_text_from_document(file_path: pathlib.Path, page_range: Optional[tuple] = None, ocr_corrections: Optional[list] = None, *, return_meta: bool = False)

   Extract text from any supported document format.

   Supports: PDF, DOCX, TXT, XLSX, CSV, DOC, HTML

   :param file_path: Path to the document
   :type file_path: Path
   :param page_range: Optional tuple (start_page, end_page) for PDF files only (1-indexed)
   :type page_range: Optional[tuple]
   :param ocr_corrections: Optional OCR text-correction rules (from ``extraction.ocr_corrections``)
                           applied to OCR-derived PDF text only.
   :type ocr_corrections: Optional[list]
   :param return_meta: Return a text/metadata pair with actual PDF scope when True.
   :type return_meta: bool

   :returns: Text, or ``(text, metadata)`` when ``return_meta`` is True.
   :rtype: str or tuple

   :raises ValueError: If file format is not supported
   :raises RuntimeError: If extraction fails

.. py:function:: read_text_cache(file_path: pathlib.Path, *, return_meta: bool = False)

   Return cached text if its source and text still match.

   Size/mtime and source SHA-256 identify the document. Text SHA-256
   rejects partial or mismatched pairs. Stem-only caches are ignored.

.. py:function:: write_text_cache(file_path: pathlib.Path, text: str, method: str = 'ocr', *, page_count: int | None = None) -> None

   Write the cache via flushed temporary files, metadata last.

   OCR callers supply raw text, never corrected text. Discovery also
   caches browser/API products under their own ``method``. Cheap native
   document parsing remains uncached.
   Each file is atomically replaced, not the pair as a transaction.
   An interruption between replacements is a miss because readers
   verify both digests. ``method`` is recorded for transparency.
