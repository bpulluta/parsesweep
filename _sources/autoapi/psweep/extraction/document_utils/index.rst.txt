.. py:function:: extract_text_from_document(file_path: pathlib.Path, page_ranges: psweep.utils.page_range.PageRanges | None = None, ocr_corrections: list | None = None, *, return_meta: bool = False, transcriber=None, source: psweep.extraction.prepared_document.CapturedSource | None = None)

   Extract text from any supported document format.

   Supports every type in ``SUPPORTED_EXTENSIONS``.

   :param file_path: Path to the document
   :type file_path: Path
   :param page_ranges: Inclusive 1-indexed ``(start, end)`` page ranges, for PDF files only
   :type page_ranges: Optional[PageRanges]
   :param ocr_corrections: Optional OCR text-correction rules (from ``extraction.ocr_corrections``)
                           applied to OCR-derived PDF text only.
   :type ocr_corrections: Optional[list]
   :param return_meta: Return a text/metadata pair with actual PDF scope when True.
   :type return_meta: bool
   :param transcriber: Transcribes uncached audio; without one, only cached transcripts.
   :type transcriber: Optional[transcription.Transcriber]
   :param source: The consumed version of ``file_path``. Content is read from its
                  snapshot; cache evidence is keyed to ``file_path`` and judged by its
                  captured digest.
   :type source: Optional[CapturedSource]

   :returns: Text, or ``(text, metadata)`` when ``return_meta`` is True.
   :rtype: str or tuple

   :raises ValueError: If file format is not supported
   :raises RuntimeError: If extraction fails

.. py:function:: read_text_cache(file_path: pathlib.Path, *, return_meta: bool = False, source_sha256: str | None = None)

   Return cached text if its source and text still match.

   Size/mtime and source SHA-256 identify the document. Text SHA-256
   rejects partial or mismatched pairs. Stem-only caches are ignored.
   With ``source_sha256`` (a captured or fingerprinted digest) that digest
   identifies the document and the live path is not reopened.

.. py:function:: write_text_cache(file_path: pathlib.Path, text: str, method: str = 'text', *, page_count: int | None = None, source: psweep.extraction.prepared_document.CapturedSource | None = None) -> None

   Write the cache via flushed temporary files, metadata last.

   A ``source`` capture supplies the identity of the bytes the text came
   from; without one the live path is read.

   Discovery caches browser/API products and extraction caches transcripts
   under their own ``method``. OCR is cached per page instead
   (:func:`ocr_page_cache`); cheap native document parsing stays uncached.
   Each file is atomically replaced, not the pair as a transaction.
   An interruption between replacements is a miss because readers
   verify both digests. ``method`` is recorded for transparency.
