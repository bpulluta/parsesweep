.. py:function:: get_model_pricing(model_name: str) -> Tuple[float, float]

   Get pricing for a model.

   Handles:

   - Exact matches: "gpt-4o-mini" -> (0.15, 0.60)
   - Partial matches: "gpt-4o" in "azure/gpt-4o" -> (5.00, 15.00)
   - Azure deployments: "compassop-gpt-4.1-mini" -> (0.40, 1.60)

   :param model_name: Model name (e.g., "gpt-4o-mini", "claude-3.5-sonnet", "compassop-gpt-4.1-mini")
   :type model_name: str

   :returns: (input_cost_per_1m, output_cost_per_1m) tuple
   :rtype: Tuple[float, float]
