.. py:class:: ExcelFormatter

   Export DataFrame to professionally formatted Excel file.

   Features:

   - Dark blue header with white bold text
   - Alternating row colors (white/light gray) for readability
   - Text wrapping enabled for long content
   - Centered alignment for short fields, left-aligned for details
   - Auto-adjusted column widths with smart limits
   - Frozen header row for scrolling
   - Clean borders throughout


   .. py:method:: save(df: pandas.DataFrame, output_path: pathlib.Path, freeze_columns: int = 0, auto_width: bool = True, center_align_columns: list[str] | None = None, center_align_max_length: float | None = None)

      Save DataFrame to professionally formatted Excel file.

      :param df: DataFrame to export
      :type df: pd.DataFrame
      :param output_path: Path for output Excel file
      :type output_path: Path
      :param freeze_columns: Number of leading columns to freeze
      :type freeze_columns: int
      :param auto_width: Whether to auto-size columns
      :type auto_width: bool
      :param center_align_columns: Column names (matched case-insensitively) that should always be
                                   center-aligned regardless of content length. Defaults to
                                   :data:`DEFAULT_CENTER_ALIGN_COLUMN_NAMES` when ``None``.
      :type center_align_columns: list[str], optional
      :param center_align_max_length: Columns whose sampled average value length is below this threshold
                                      are center-aligned. Defaults to
                                      :data:`DEFAULT_CENTER_ALIGN_MAX_LENGTH` when ``None``.
      :type center_align_max_length: float, optional

      .. rubric:: Examples

      >>> formatter = ExcelFormatter()
      >>> formatter.save(df, Path("output.xlsx"))
